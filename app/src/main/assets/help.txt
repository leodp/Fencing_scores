This app is used to log & calculate the results of a small fencing tournament, with possibility to repeat the same pools in up to 5 rounds and merge results from distinct ones KO matches are offered with various combination modes

INTERACTION:
------------
When launching the app you are presented the pools page. You can interact with it quite intuitively.

Pressing the Nr column shows the upcoming bouts:
Long pressing last cells in the Nr col. adds 1 participant
Long pressing first cells in the Nr col. removes 1 participant

Select a participant name to define/cancel it
Bout results are defined/reset in the bouts area

The top row prepares a QR code to screenshot or export the status

Touch Position cells to show this help
Touch results cells to change their color

-----------------------------------------------------------------

Results are calculated every time a bout is entered
You can also use saved CSV files or QR codes to reload a previous status. QR codes are quick means to share data between phones.
ATTENTION: if the program crashes, backup files (updated at each interaction) will help restore the results. Do NOT enter again data: Use the RESTORE buttons instead


OVERVIEW ACTIONS -------------------------------------------------

# Fencing Scores App - Actions Reference

## Pages (circular navigation)
**Rounds1..RoundsN → Merged → KO → Final → Rounds1 (N = 1..5)**

## Navigation (All Pages)
Swipe left  : Next page
Swipe right : Previous page
Long press  : Next page (Final → Round wraps)


## Round Pages
Nr cells : Click : Show upcoming planned bouts
Nr cells (top half) : Long press : Remove last participant row
Nr cells (bottom half) : Long press : Add participant row
Name header ("Round Nr: X") : Click/long press : Set rounds nr. (1..5). Rounds pages can be used to repeat the same pool or define others with different participants. Take care of using unique names
Name cells : Click : Edit name
Name cells : Long press : Sort by name
Bout cells : Click : Enter scores
V/→/←/I/% cells : Click : Cycle color theme
P cells : Click : Show Help dialog
P cells : Long press : Sort by ranking
Result cells : Long press : Go to Merged
Other Headers : Click : Show QR code


**Help Dialog :** load/save pools-rounds & show help


## Merged Page
Nr cells (top half) : Long press : Remove last participant
Nr cells (bottom half) : Long press : Add participant
Name/V/→/←/I/%/P cells : Click : Edit value
Name cells : Long press : Toggle sort A-Z / Z-A
FinalPos cells : Click : Edit position
FinalPos cells : Long press : Toggle sort FinalPos
P cells : Long press : Toggle sort P
Any other cell : Long press : Go to KO


## KO Page
Black KO button : Menu : Change KO modus
Match button : Click : Enter match scores

**Match popup Dialog:** Score buttons (0-15), RESET, CANCEL


## Final Page
Read-only rankings display.
Long press : Go back to Round


## Automatic Backup
Each page backs up to `{Page}_backup.csv` on changes
Automatic crash detection via CRASH.txt flag file
Backup recovered with RESTORE buttons
QUIT performs a clean exit: all backup files are deleted and next start is clean

## QR Codes
To help sharing info between devices
Useful to import ranking of other pools in Merged page (for organizing KO rounds)
